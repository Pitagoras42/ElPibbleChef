# El Pibble Chef

Sitio web promocional para un servicio de chefs y meseros a domicilio, pensado para eventos privados, celebraciones y reuniones especiales.

La página presenta los paquetes de servicio, el equipo de trabajo, una galería de eventos, información de contacto y apartados legales.

## ✨ Funcionalidades principales

1. **Menú de navegación desplegable:** acceso a servicios, equipo, eventos, reservas, términos y condiciones y política de privacidad.
2. **Paquetes de servicio:** presentación de los planes Pro, Normal y Básico, con precios, duración y descripción.
3. **Presentación del equipo:** perfiles de dos chefs y dos meseros, con imágenes y descripciones personalizables.
4. **Galería interactiva:** imágenes de eventos que pueden abrirse en un visor ampliado (*lightbox*).
5. **Contacto e información legal:** datos de contacto, términos y condiciones y política de privacidad en bloques desplegables.

## 🧰 Stack tecnológico

- **HTML5:** estructura y contenido.
- **CSS3:** estilos, diseño visual y adaptación a distintos tamaños de pantalla.
- **JavaScript Vanilla:** menú desplegable, interacción del encabezado, apertura de contenido legal, galería ampliada y actualización automática del año.
- **SVG:** imágenes vectoriales locales de ejemplo.
- **Google Fonts:** tipografías DM Sans y Syne.

El proyecto no utiliza frameworks ni requiere instalar paquetes para ejecutarse.

## 🚀 Instalación: clonar el repositorio

### Requisitos

- [Git](https://git-scm.com/) instalado.
- Un navegador moderno, como Brave, Chrome, Firefox o Edge.

### Pasos

1. Abre una terminal.
2. Clona el repositorio:

   ```bash
   git clone https://github.com/USUARIO/REPOSITORIO.git
   ```

   Sustituye `USUARIO/REPOSITORIO` por la dirección real del repositorio de GitHub.

3. Entra en la carpeta del proyecto:

   ```bash
   cd REPOSITORIO
   ```

4. Abre `Index.html` en tu navegador.

### Ejecución opcional con servidor local

Si utilizas Visual Studio Code, puedes abrir la carpeta del proyecto y ejecutar `Index.html` con la extensión **Live Server**.

No es necesario ejecutar `npm install` ni instalar dependencias.

## ℹ️ Notas importantes

- Conserva `Index.html`, `styles.css`, `main.js` y la carpeta `images` en sus ubicaciones.
- Las imágenes SVG incluidas son ilustraciones provisionales; reemplázalas por fotografías autorizadas antes de publicar.
- Actualiza los nombres, perfiles, redes sociales y datos de contacto con información real.
- Revisa los términos y la política de privacidad según la legislación del país donde opere el negocio.
- Google Fonts necesita conexión a Internet para cargar DM Sans y Syne.
