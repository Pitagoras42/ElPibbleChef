El Pibble Chef
Sitio web promocional de servicio de chefs y meseros a domicilio
================================================================

DESCRIPCIÓN
-----------
El Pibble Chef es una página web promocional para un servicio gastronómico a domicilio
orientado a eventos privados y celebraciones. Presenta los paquetes de servicio,
el equipo de trabajo, una galería de eventos, información de contacto y secciones
legales.

5 FUNCIONALIDADES (FEATURES)
----------------------------
1. Menú de navegación desplegable:
   Permite acceder rápidamente a las secciones de servicios, equipo, eventos,
   reservas, términos y condiciones y política de privacidad.

2. Presentación de paquetes de servicio:
   Muestra los planes Pro, Normal y Básico, con sus precios, duración y descripción.

3. Sección del equipo:
   Presenta los perfiles de los dos chefs y dos meseros, con imágenes y datos
   descriptivos que pueden personalizarse.

4. Galería interactiva de eventos:
   Muestra imágenes de referencia y permite abrirlas en un visor ampliado (lightbox).

5. Información de contacto y secciones legales:
   Incluye los datos de contacto del negocio, términos y condiciones y política
   de privacidad mediante bloques desplegables.

STACK TECNOLÓGICO
-----------------
- HTML5: estructura y contenido de la página.
- CSS3: diseño visual, colores, distribución y adaptación a distintos tamaños
  de pantalla.
- JavaScript (Vanilla): menú desplegable, cierre del menú, efectos del encabezado,
  apertura de contenido legal, galería ampliada y actualización automática del año.
- SVG: imágenes vectoriales locales utilizadas como recursos visuales de ejemplo.
- Google Fonts: tipografías DM Sans y Syne, cargadas desde Google Fonts.

No utiliza frameworks ni requiere instalación de paquetes para ejecutarse.

INSTALACIÓN Y EJECUCIÓN
-----------------------
Requisitos:
- Git instalado.
- Un navegador moderno (Brave, Chrome, Firefox, Edge, etc.).

1. Clonar el repositorio:
   git clone https://github.com/USUARIO/REPOSITORIO.git

   Reemplaza USUARIO/REPOSITORIO por la dirección real del repositorio de GitHub.

2. Entrar en la carpeta:
   cd REPOSITORIO

3. Abrir el archivo Index.html:
   - En Windows, puedes hacer doble clic en Index.html.
   - También puedes abrirlo desde el navegador.

4. (Opcional) Ejecutar con un servidor local:
   Si tienes Visual Studio Code, abre la carpeta del proyecto y utiliza la
   extensión Live Server. Luego selecciona "Open with Live Server".

No es necesario ejecutar npm install ni instalar dependencias.

IMPORTANTE
----------
- Mantén Index.html, styles.css, main.js y la carpeta images en sus ubicaciones.
- Las imágenes SVG incluidas son ilustraciones provisionales de ejemplo.
- Sustituye los perfiles, fotografías, redes sociales, credenciales y datos de
  contacto por información real y autorizada antes de publicar.
- Revisa los textos legales según la normativa aplicable en el país donde opere
  el negocio.
- Google Fonts requiere conexión a Internet para cargar las tipografías externas.
